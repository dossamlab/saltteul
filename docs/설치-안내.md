# 살뜰 설치 안내

살뜰을 우리 집에서 쓰도록 처음부터 설치하는 순서입니다. 한 가족, 두 사람이 쓰는 구성입니다. 아래 예시의 `my-saltteul`, `my-saltteul.vercel.app`, 이메일 주소는 자기 값으로 바꿔 씁니다.

준비물:

- 구글 계정 두 개(앱에 들어올 두 사람)
- Node.js 22, Git, [Firebase CLI](https://firebase.google.com/docs/cli)(`npx firebase`로도 됨)
- 안드로이드 APK를 직접 만들 때만: JDK 21, Android SDK

## 1. Firebase 프로젝트

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만들고 사용량 요금제(Blaze)로 바꿉니다. 서버 함수에 필요합니다. 예산 알림을 1달러쯤으로 걸어 두면 안심입니다.
2. Firestore: 데이터베이스를 만듭니다. 위치는 서버 함수와 같은 `asia-northeast3`(서울)을 권합니다.
3. Authentication: 「로그인 방법」에서 Google을 켭니다. 「설정 → 승인된 도메인」에 웹앱을 올릴 주소(예: `my-saltteul.vercel.app`)를 넣습니다.
4. 웹 앱 등록: 프로젝트 설정에서 웹 앱을 추가하고 나오는 설정값 6개를 적어 둡니다.
5. 웹 푸시 키: 프로젝트 설정 → 클라우드 메시징 → 「웹 푸시 인증서」에서 키 쌍을 만들고 공개 키를 적어 둡니다.
6. 안드로이드 앱 등록(안드로이드를 쓸 때): 패키지 이름 `kr.saltteul.app`으로 추가합니다. 서명 지문(SHA-1, SHA-256)은 6절에서 키를 만든 뒤 넣고, 그다음 `google-services.json`을 받습니다.
7. `.firebaserc`의 `saltteul-family`를 자기 프로젝트 ID로 바꿉니다.

## 2. 구글 클라우드 API

같은 프로젝트를 [구글 클라우드 콘솔](https://console.cloud.google.com/apis/library)에서 열고 아래 두 API를 켭니다.

- Google Calendar API: 할 일과 캘린더 동기화
- Cloud Speech-to-Text API: 빠른 입력의 음성 입력. 매달 일정 시간까지는 무료이고 넘으면 요금이 나옵니다. 최신 가격은 구글 가격표에서 확인합니다.

## 3. 서버 함수 설정

1. `functions/.env.<프로젝트ID>` 파일을 만들고 앱에 들어올 두 계정을 적습니다. 이 파일은 저장소에 올라가지 않습니다.

   ```
   HUSBAND_EMAIL=first@example.com
   WIFE_EMAIL=second@example.com
   ```

   역할 이름이 남편·아내로 정해져 있어서 화면의 담당 표시도 두 사람 기준으로 나옵니다. 이 두 주소 말고는 로그인해도 들어올 수 없습니다.

2. 비밀값 두 개를 넣습니다. 명령을 실행하면 값을 묻는 창이 뜹니다.

   ```
   npx firebase functions:secrets:set ANTHROPIC_API_KEY
   npx firebase functions:secrets:set KMA_SERVICE_KEY
   ```

   - `ANTHROPIC_API_KEY`: [Claude Console](https://console.anthropic.com)에서 만든 API 키. 브리핑, 빠른 입력, 알림장 읽기, 식단표 읽기, 저녁 메뉴에 씁니다.
   - `KMA_SERVICE_KEY`: [공공데이터포털](https://www.data.go.kr)에서 「기상청_단기예보 조회서비스」를 활용 신청해 받은 디코딩 키.
   - 키가 없으면 그 기능만 멈춥니다. 예를 들어 클로드 키가 없으면 브리핑이 기본 요약으로 나갑니다.

3. 서버 함수와 보안 규칙을 올립니다.

   ```
   npm ci
   (cd functions && npm ci)
   npx firebase deploy --only functions,firestore
   ```

   윈도에서 폴더 이름에 한글이 있으면 배포 도구가 경로를 못 읽을 수 있습니다. 그때는 영어로 된 경로에 저장소를 두고 실행합니다.

## 4. 웹앱(아이폰과 PC용)

1. 저장소 루트에 `.env.production`을 만들고 1절에서 적어 둔 값을 넣습니다. 이 파일도 저장소에 올라가지 않습니다.

   ```
   VITE_FIREBASE_API_KEY=...
   VITE_FIREBASE_AUTH_DOMAIN=my-saltteul.firebaseapp.com
   VITE_FIREBASE_PROJECT_ID=my-saltteul
   VITE_FIREBASE_STORAGE_BUCKET=...
   VITE_FIREBASE_MESSAGING_SENDER_ID=...
   VITE_FIREBASE_APP_ID=...
   VITE_FIREBASE_VAPID_KEY=(1절 5번의 웹 푸시 공개 키)
   ```

2. `src/pwa/liveUpdate.ts`의 `UPDATE_MANIFEST_URL`을 자기 웹 주소로 바꿉니다(예: `https://my-saltteul.vercel.app/app-update/latest.json`). 안드로이드 앱이 새 화면을 받아 오는 주소입니다.
3. [Vercel](https://vercel.com)에 저장소를 가져오고, 프로젝트 설정의 환경 변수에 위 7개 값을 넣습니다. 빌드 명령은 `vercel.json`에 들어 있습니다(`npm run build:web`). 다른 호스팅을 쓰려면 `npm run build:web`으로 만든 `dist` 폴더를 올리면 됩니다.

## 5. 앱 안에서 처음 설정

두 사람 모두 웹앱이나 안드로이드 앱에서 구글로 로그인한 뒤, 설정 화면에서 다음을 정합니다.

1. 내 이름과 우리 집 이름: 브리핑과 담당 표시에 쓰입니다.
2. 날씨 지역: 「현재 위치로 설정」을 누르거나 동 이름으로 찾습니다.
3. 구글 캘린더(선택):
   - 한 사람의 구글 캘린더에서 새 캘린더(예: 「우리집」)를 만듭니다.
   - 「특정 사용자와 공유」에 두 사람과 서버 계정 `<프로젝트 번호>-compute@developer.gserviceaccount.com`을 「일정 변경」 권한으로 넣습니다. 프로젝트 번호는 Firebase 프로젝트 설정에 있습니다.
   - 캘린더 설정의 「캘린더 ID」를 살뜰 설정의 캘린더 ID 칸에 붙여 넣습니다.
4. 키즈노트(선택): 키즈노트 아이디와 비밀번호로 연결합니다. 비밀번호는 저장하지 않고 로그인 세션만 서버 전용 문서에 둡니다. 2단계 인증을 켠 계정은 연결할 수 없습니다. 세션이 끝나면 다시 연결해야 합니다.
5. 알림: 「알림 받기」를 눌러 브리핑과 부탁 알림을 받습니다.

## 6. 안드로이드 APK 만들기

GitHub에서 태그를 올리면 서명된 APK가 자동으로 만들어지게 해 둡니다.

1. 서명 키를 만듭니다. 이 키와 비밀번호를 잃어버리면 같은 앱으로 업데이트할 수 없으니 안전한 곳에 따로 보관합니다.

   ```
   keytool -genkeypair -keystore release.jks -storetype PKCS12 -alias saltteul -keyalg RSA -keysize 4096 -validity 10000
   keytool -list -v -keystore release.jks
   ```

2. 두 번째 명령에 나온 SHA-1과 SHA-256을 Firebase의 안드로이드 앱(1절 6번)에 넣고, `google-services.json`을 받아 `android/app/`에 둡니다. 지문을 넣지 않으면 앱에서 구글 로그인이 되지 않습니다.
3. GitHub 저장소의 「Settings → Secrets and variables → Actions」에 비밀값 12개를 넣습니다.

   | 이름 | 값 |
   |---|---|
   | `VITE_FIREBASE_*` 7개 | 4절의 값과 같음 |
   | `GOOGLE_SERVICES_JSON_BASE64` | `google-services.json`을 base64로 바꾼 값 |
   | `ANDROID_KEYSTORE_BASE64` | `release.jks`를 base64로 바꾼 값 |
   | `ANDROID_KEYSTORE_PASSWORD` | 키 저장소 비밀번호 |
   | `ANDROID_KEY_PASSWORD` | 키 비밀번호(1번 명령에서 따로 정하지 않았으면 위와 같음) |
   | `ANDROID_KEY_ALIAS` | `saltteul` |

   GitHub CLI를 쓰면 `base64 -w0 release.jks | gh secret set ANDROID_KEYSTORE_BASE64`처럼 넣을 수 있습니다.

4. 버전 태그를 올립니다. 몇 분 뒤 Releases에 `saltteul-0.3.0.apk`가 붙습니다.

   ```
   git tag -a v0.3.0 -m "첫 판"
   git push origin v0.3.0
   ```

## 7. 휴대폰에 설치

**안드로이드**

1. 휴대폰 브라우저로 자기 저장소의 Releases(예: `https://github.com/<계정>/saltteul/releases/latest`)를 열고 `saltteul-x.y.z.apk`를 받아 설치합니다. 「출처를 알 수 없는 앱 설치」 허용을 묻는 창이 뜨면 브라우저에 허용합니다.
2. 살뜰을 열어 구글로 로그인합니다. 홈 화면을 길게 눌러 살뜰 위젯(대시보드, 할 일, 태블릿 보드, 상비품)을 추가합니다.
3. 빠른 입력의 마이크 버튼을 처음 누를 때 마이크 권한을 허용합니다.
4. 다음부터는 새 APK가 나오면 앱 위쪽에 「새 버전이 나왔어요 [받기]」 띠가 뜹니다. 「받기」를 누르면 브라우저가 내려받고, 설치 확인을 한 번 누르면 됩니다. [Obtainium](https://github.com/ImranR98/Obtainium)에 저장소를 등록해 받는 방법도 있습니다.

**아이폰**

1. 사파리로 웹앱 주소를 열고 공유 버튼에서 「홈 화면에 추가」를 누릅니다.
2. 홈 화면 아이콘으로 연 뒤 설정에서 「알림 받기」를 누릅니다. 알림은 iOS 16.4 이상에서, 홈 화면에 추가한 앱으로 열었을 때만 됩니다.

## 8. 업데이트

- **화면만 바꿨을 때**: 웹을 다시 배포합니다. 아이폰과 PC는 바로 바뀌고, 안드로이드 앱은 다음에 켤 때 새 화면을 받아 그다음 실행부터 씁니다.
- **안드로이드 본체를 바꿨을 때**(위젯, 권한, 네이티브 플러그인): 새 화면이 새 본체 없이는 돌지 않을 때만 `scripts/update-config.json`의 `minNative`를 새 버전으로 올립니다. 웹을 배포한 뒤 새 태그를 올리면, 앱이 띠로 새 버전을 알려 줍니다. 옛 APK는 새 APK를 설치할 때까지 지금 화면을 그대로 씁니다.

## 시험 서버로 먼저 써 보기

Firebase 프로젝트 없이 이 PC에서 돌려 볼 수 있습니다(JDK 21 필요).

```
npx firebase emulators:start --project demo-saltteul
node scripts/seed.mjs
npm run dev
```

브라우저에서 http://localhost:5180 을 열고 husband@example.com 또는 wife@example.com으로 들어갑니다.
